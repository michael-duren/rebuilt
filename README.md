# Rebuilt

A list of mostly unix tools I've rebuilt with go

## About

Rebuilt is a collection of tools I've been rebuilding or new tools I've built in go. These are for me to get a better
understanding of the lower level or common tools developers use on a daily basis.

## Installation

I don't know why you'd want to do this, but here's how to do it anyway:
To install any of these tools, run `go install github.com/michael-duren/rebuilt/<tool-name>`.
